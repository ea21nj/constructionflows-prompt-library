Technical Tool Stack

The core philosophy is to use agents to build agents, reducing manual coding required by solo founders.

1. Agent Frameworks (The Harnesses)

Hermes

Recommended as the most reliable and flexible "harness" because it allows you to switch models easily and is self-evolving.

Claude Code & OpenAI's Codex

Desktop apps used by the founder to actually build and install the customer agents.

2. Core Models

GPT 5.5

Identified as the most efficient model for tool calls and general usage.

Opus 4.7

Best for long-horizon coding tasks.

GLM 5.1 or Kimmy

Used for lighter-weight, more affordable open-source tasks.

3. Infrastructure & Memory

Orgo

A workspace that provides cloud computers (VMs) where agents live. This allows the founder to manage and debug agents remotely in a secure, isolated environment.

Obsidian

Acts as the agent's "second brain." By providing the agent with well-structured markdown files in an Obsidian vault, it gains permanent context on the business, people, and projects.

4. Connectivity & Skills

Composio

A vital connector that gives agents access to thousands of apps (Gmail, Slack, Notion) while handling complex authentication and security.

Agent Mail

Provides each agent with its own dedicated email address to act as a true personal assistant.

MCPs (Model Context Protocol)

Specialized tools like Perplexity MCP (for up-to-date knowledge), Context 7 (for GitHub docs), and XMCP (for Twitter/X insights) are used to give agents the latest information needed for setup.

5. Customer Management

Trello

Used as a customer-facing board for request management (e.g., a "to-do" list for new agent skills).

Granola

For meeting notes that automatically sync to Trello.

Loom

For sending video updates to customers regarding agent improvements.

What is an agent?

An agent is a repeatable workflow using AI to handle tedious work: summarizing, organizing, flagging, drafting. Your team approves final decisions. It reduces paperwork, prevents missed deadlines, protects margin, and helps you get paid faster.
