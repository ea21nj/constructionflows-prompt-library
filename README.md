# Eligeo Prompt Library Landing Page

A Vercel-style landing page for the Eligeo construction AI prompt library.

## What it includes

- Hero section for the prompt library
- Workflow positioning for contractors
- Interactive prompt library tabs
- Use-case / offer section
- Starter-pack CTA
- Mobile-responsive design

## Development

```bash
npm install
npm run start
```

## Build

```bash
npm run build
```
