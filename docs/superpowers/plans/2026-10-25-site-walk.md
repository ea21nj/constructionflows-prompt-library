# Site Walk Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the prompt library's homepage with a Sims-style 3D construction site where the visitor walks a worker around, talks to ten crew members (one per agent) who ask discovery questions, and collects ranked results in the site office.

**Architecture:** The game is a full-screen layer added to the existing single-page `index.html`; its code lives in ES modules under `src/game/`, bundled by the existing Vite build. Pure logic (crew content, progress state, scoring, collision, report text) is separated from rendering so it can be unit-tested. The existing inline script keeps the classic pages and exposes what the game reuses on `window.WP`. 3D uses Three.js with free CC0 models stored under `public/assets/site/`.

**Tech Stack:** Vite (existing), Three.js 0.160+, Vitest + jsdom (unit), Playwright (e2e, Chromium with SwiftShader WebGL), `@gltf-transform/cli` (asset compression at prep time only).

**Spec:** `docs/superpowers/specs/2026-10-25-site-walk-design.md` (read it first). Approved prototype for controls and feel: `.superpowers/brainstorm/86914-1792962627/content/site-3d-spike-v2.html` (git-ignored, local only).

## Global Constraints

- Assets: free, CC0 (or equivalent: commercial use, no attribution requirement), shipped as GLB. **Downloading any asset pack needs the owner's go-ahead first** (name, source URL, licence, size).
- UI style for every overlay: green `#008037` (hover/edge `#006830`), ink `#1A1A1A`, background `#F5F5F5`, IBM Plex Mono (headings/labels) + IBM Plex Sans (body), 2px solid borders, square corners. Reuse the CSS tokens already on `:root` in `index.html`.
- Desktop controls (fixed by the approved prototype): WASD / arrow keys walk (relative to camera), Shift run, E / Space / Enter talk, 1–4 answer, Esc leave, mouse drag rotates, wheel zooms.
- Phone: on-screen joystick to walk, tap a worker to talk, a Talk button when near.
- Office unlocks after **3** completed conversations (all 3 questions answered).
- Opening card copy (verbatim): "Walk the site and talk to the crew — each one is an AI agent that could help your business. After you've met 3, head to the site office for your results. Prefer the classic pages? Use the menu." Buttons: "Start walking", "Skip to the agents".
- Objective line copy: "Talk to the crew · {n} of 3" → "Site office is open — head there". Unlock toast: "The site office is open".
- Talk prompt copy: "Press E to talk to {Name} — {Role}" (phones: a "Talk to {Name}" button).
- Progress lives only in `localStorage` key `wp.sitewalk.v1`; every read/write wrapped in try/catch; the game must work with storage unavailable.
- Never a blank screen: loading screen with progress until the scene is ready; if WebGL is unavailable, show the classic pages with the note "Your browser can't run the 3D site, so here are the classic pages."
- Classic pages (Agent quiz, 10 Agents with tabbed dialog, Discovery voice interview + document, About, `/api/contact`) keep working unchanged.
- Performance: desktop target 60 fps, mid-range phone ≥ 30 fps; total game download ≤ 12 MB compressed; `low` quality tier disables shadows and post-processing and caps pixel ratio at 1.
- Respect `prefers-reduced-motion` (no camera glides, no typewriter text, no bobbing UI).

## Review Focus

1. Returning visitor with saved progress (office already open, some crew met) — game restores exactly that state, office marker shown, objective correct; corrupt or old JSON in `wp.sitewalk.v1` falls back to a fresh start instead of crashing. → Task 2 tests `loadState` with corrupt JSON and with a v0 shape.
2. Player wedged against or spawned inside an obstacle (resize, auto-walk, teleport) — movement must always slide free, never freeze. → Task 3 test `moveWithSlide` from a point inside a box pushes out.
3. Visitor opens a deep link (`/#agents`, `/#quiz`, `/#discovery`, `/#about`) — classic page opens directly, game not started. → Task 4 e2e `deep link skips game`.
4. Agent details dialog opened from the results board must sit above the board and return focus to the board on close. → Task 9 e2e `view details from results`.
5. Phone rotated or resized mid-conversation — panel, joystick and minimap stay on screen, no horizontal scroll. → Task 10 e2e `resize during talk`.

## Shared interfaces (used across tasks)

```js
// content.js
export const AREAS: { id, label, rect: [minX, maxX, minZ, maxZ] }[]
export const OFFICE: { door: [x, z], trigger: [minX, maxX, minZ, maxZ], footprint: [minX, maxX, minZ, maxZ] }
export const SPAWN: [x, z]
export const CREW: {
  agentId: number,            // matches agents[].id in index.html (1–10)
  name: string, role: string, area: string,
  spot: [x, z], route: [x, z][], activity: 'plans'|'laptop'|'board'|'clipboard'|'drawings'|'photo'|'log'|'delivery'|'chat'|'sit',
  questions: { q: string, answers: [string, string, string, string] }[]   // exactly 3, answers ordered least→most pain
}[]
// state.js
export const STORAGE_KEY = 'wp.sitewalk.v1'
export function createState(): State      // { v: 1, answers: { [agentId]: number[] }, lastTalked: { [agentId]: number }, officeSeen: boolean }
export function loadState(storage?): State
export function saveState(state, storage?): void
export function recordAnswer(state, agentId, qIndex, choice, now = Date.now()): State   // returns new state
export function isComplete(state, agentId): boolean   // all 3 answered
export function completedCount(state): number
export function officeOpen(state): boolean            // completedCount >= 3
export const OFFICE_UNLOCK = 3
// scoring.js
export function fit(state, agentId): number            // 0–9, sum of answer indexes
export function rank(state, crew = CREW): { agentId, name, role, fit, complete, why: string[] }[]   // complete first by fit desc, tie → lastTalked desc; incomplete after
// collision.js
export const SOLID: [minX, maxX, minZ, maxZ][]; export const BOUNDS: [minX, maxX, minZ, maxZ]
export function blocked(x, z, r = 0.45): boolean
export function moveWithSlide(pos: {x, z}, dx, dz, r = 0.45): {x, z}
// report.js
export function reportMarkdown(state, details, date = new Date()): string
export function reportHtml(state, details, date = new Date()): string   // markup using the existing #dvPrint .pr-* classes
// index.html (classic script) → window.WP
window.WP = { agents, showAgentModal(agent, opener), openClassic(faceId = 'agents'), showSiteWalk() }
```

World coordinates: 1 unit = 1 m, y up, site interior `x -66..66, z -40..40`, street along `z 42..48`, gate at `(-1.5, 38)`. Derived from the approved plan (svg → world: `x = (svgX − 480) × 0.15`, `z = (svgY − 280) × 0.15`).
